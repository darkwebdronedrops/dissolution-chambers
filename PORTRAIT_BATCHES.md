## Agent Kimi Prompting Guidelines

### For EACH batch:
1. **Show this character description first**
2. **Ask for 2-3 variants per portrait** (same expression, slightly different compositions/lighting)
3. **Specify transparent background or simple gradient** (not busy backgrounds — these are UI portraits)

### Example full prompt:

```
Generate 5 portrait images of an original character named Kira:

Character description: Purple-skinned female figure with small curved black ram horns (subtle pink inner glow), short dark hair, anime-influenced art style.

Batch: Snowbunny — Warmth & Eros
1. Warm: Open smile, relaxed, happy — warm golden light
2. Aroused: Heavy-lidded, suggestive without explicit — deep amber light
3. Pleading: Wide eyes, vulnerable, leaning forward — soft candlelit
4. Content: Peaceful half-smile, sated — warm golden hour
5. Dissolved: Breaking into warm golden particles while smiling — ethereal particle effect

Please generate 2-3 variants of each for selection. Transparent backgrounds. Portrait format.
```

### Content Safety Notes
- Avoid: explicit nudity, sexual acts, violence, gore
- Safe: suggestive expressions, emotional intensity, fantasy aesthetic, implied intimacy
- If a portrait gets flagged, rephrase: "warm and inviting expression" instead of "aroused"
